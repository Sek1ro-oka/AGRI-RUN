# 路线工坊（Route Workshop）

一个**完全离线**的 Android 小工具：在地图上点出一条闭合路线，设置速度与圈数，然后用**Android 系统模拟位置**把
“沿这条路线匀速跑 N 圈”的坐标源源不断地喂给系统，让第三方运动 App 以为你在跑圈。

- 包名：`org.localroute.app`　版本：0.2.0（versionCode 5）
- 最低系统：Android 10（API 29），编译 SDK 35
- 无账号、无网络请求（地图瓦片除外）、无服务器、数据只存在手机本地
- 附带一个独立包名的小工具 **定位探针**（`org.localroute.probe`），用来独立验证“系统确实收到了坐标”

> 本仓库按 `E:\agri-run\路线工具_开发任务书_v1.md` 开发，只做任务书里的 P0 范围。
> 它不修改、不注入、不 hook 任何第三方应用；是否采信模拟位置由系统与第三方应用自己决定。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 地图选点 | MapLibre + 瓦片底图（默认高德，可切 OSM）；单击加点，拖动/双指缩放不会误加点；加第一个点或点落在视野外时自动取景（0.1.3） |
| 路线编辑 | 撤销、清空、手动输入经纬度（WGS-84，纬度在前）、实时显示单圈长度 |
| GPX 互转 | 菜单「导出 GPX 到文件」「从 GPX 文件导入」：`trk` 单段折线，导出后可交给其它工具，导入外部轨迹也能直接跑（0.1.3） |
| 闭合开关 | 菜单里可切换「最后一点是否连回起点」：不闭合时按**原路返回**计圈（0.1.1） |
| 单点位置 | 菜单「发送单点位置」直接输入一个坐标，前台服务把模拟位置钉在那里（速度 0），直到停止（0.1.1） |
| 地图兜底 | 底图默认「高德地图（GCJ-02，非官方接口）」，另有 OSM 官方 / OSM France / OSM Germany 可切；样式 10 秒内没就绪、或瓦片探测确认不可达时，把原因显示在地图区（0.1.1 起，0.1.3 改为默认高德） |
| 传送 | 菜单「传送到地图选点」：在地图上点一下，模拟位置立刻搬到那一点并钉住（速度 0），可随时停止（0.1.2） |
| 国内底图 | 可切换「高德地图（GCJ-02）」：底图与点位之间自动做 WGS-84 ↔ GCJ-02 换算，路线不会漂移（0.1.2） |
| 位置自检 | 诊断页把「应用提交的坐标」与「系统读回的坐标」并排对比，给出「系统已接受 / 偏差过大 / 未收到 / 无模拟标记」结论（0.1.2） |
| 运行参数 | 速度 0.5–60 km/h（默认 9）、圈数 1–1000（默认 5）、每 500 ms 提交一次位置 |
| 运行控制 | 开始 / 暂停 / 继续 / 停止；重复点击不会产生第二个任务 |
| 运行展示 | 状态、当前位置、速度、累计距离、已完成圈数、有效运行时间（暂停不计时） |
| 模拟位置 | `LocationManager.addTestProvider` + `setTestProviderEnabled` + `setTestProviderLocation`，GPS 必测，NETWORK/FUSED 支持则一并提交 |
| 前台服务 | `foregroundServiceType="location"`，常驻通知上直接暂停/继续/停止；锁屏继续输出 |
| 本地保存 | 一条路线一个 JSON（文件名用路线 ID），写入走临时文件 + fsync + 原子替换；损坏文件隔离到 `corrupt/` |
| 设置检查 | 逐个检查“是否选为模拟位置应用、定位权限、系统定位开关、通知权限、电池优化” |
| 诊断信息 | 包名/版本/API/机型/当前状态/provider 支持矩阵；坐标日志默认关闭 |

## 快速开始

1. 安装 `delivery/路线工坊-0.2.0-release.apk`（另附 `定位探针` APK）。
2. 手机 **开发者选项 → 选择模拟位置信息应用 → 路线工坊**（0.1.1 起本应用才会出现在这个列表里）。
3. 打开 App 授予定位权限，打开系统定位；菜单「设置检查」逐项确认全部通过。
4. 地图上点 3–4 个点围出一圈，填速度与圈数，点「开始」。
5. 只想让位置停在某一点时，用菜单「发送单点位置」输入经纬度后点「发送」。
6. 通知栏出现常驻通知，第三方运动 App 里应当能看到位置在移动。
7. 用「定位探针」独立复核：开始监听后应看到坐标在变、并标注为模拟位置。
8. 换设备或换工具时可以用 GPX 中转：菜单「导出 GPX 到文件」存到 `Download/`，再「从 GPX 文件导入」还原。

完整步骤与验收清单见 `delivery/README_安装与使用.md`。

## 0.1.1 变更（针对真机反馈）

| 反馈 | 处理 |
| --- | --- |
| 打开后地图一片黑 | 瓦片源不再写死：默认 OSM 官方，另备 OSM France 与 OSM Germany；地图区域先铺浅灰底 + 「地图加载中」提示；样式 10 秒未就绪就把原因显示在底部，并保留手动输入与单点发送。菜单「地图瓦片源」可随时切换 |
| 点 3 个点就自动连回起点 | 闭合改为用户可选（菜单「闭合路线」，勾选 = 连回起点）。不闭合时运行到终点后**沿原路返回**，一圈 = 单程的两倍，界面显示「不闭合（原路返回）· 单圈」 |
| 开发者选项的模拟位置应用列表里没有本应用 | 清单补声明 `android.permission.ACCESS_MOCK_LOCATION`（AOSP 的 AppPicker 用它过滤候选应用），已用 aapt2 确认 0.1.1 的 APK 里包含该权限 |
| 想直接传送单点位置 | 菜单「发送单点位置」：输入经纬度（默认填地图中心），前台服务每 500 ms 提交同一个坐标、速度 0，通知栏可停止 |

测试：0.1.1 当时是 107 个 JVM 用例（route-core 56 / simulation-core 16 / app 35），lint 0 error。

## 0.1.2 变更（针对第二轮反馈）

| 反馈 | 处理 |
| --- | --- |
| 想要「把当前定位传送到地图上选点」 | 菜单「传送到地图选点」：进入后点一下地图，模拟位置立刻搬到该点并钉住（速度 0），复用单点模式的前台服务与通知；再点一次菜单或点「停止」结束。运行中会先要求停止，避免一个任务被两个入口抢 |
| 地图太老，想用高德/百度 | 菜单「地图瓦片源」新增 **高德地图**（GCJ-02）。高德底图与 WGS-84 之间自动做双向换算（新增 `ChinaShift`：正向公式 + 5 次不动点迭代求逆），在高德底图上点选的点也会先转回 WGS-84 再存，因此换底图不会让路线漂移。百度未接入（其瓦片是 BD-09 私有矢量接口，需要官方 SDK key；见 `docs/ISSUES.md` I-036） |
| 「还没办法真正实现虚拟定位」 | 新增**位置自检**：诊断页每 3 秒读一次 `LocationManager.getLastKnownLocation(gps/network/fused)`，与前台服务最后提交的坐标对比，给出「系统已接受（偏差 X 米，带模拟标记）／偏差过大／未收到／无模拟标记」四种结论并解释该怀疑谁。若自检显示 gps 已接受而目标 App 仍不动，说明是目标 App 自己过滤模拟位置（本应用无权、也不应绕过） |

测试：**144 个 JVM 用例**（route-core 78 / simulation-core 24 / app 42），lint 0 error（app 16 warning、探针 1 warning）；另有 API 35 模拟器实测记录，见 `docs/04_模拟器实测记录.md`。
当时的真机行为（传送是否立刻生效、高德底图是否可达、自检四种结论的真实表现）尚未实测；0.1.3 已在模拟器上补齐大部分，
真机仍未复验，见 `delivery/KNOWN_ISSUES_已知问题.md`。

## 0.1.3 变更（模拟器实测 + 子代理功能）

| 事项 | 处理 |
| --- | --- |
| 底图在国内/模拟器里打不开 | 根因是 OSM 域名解析到黑洞地址（`10.112.4.179`）后 `SSLHandshakeException`。默认瓦片源改为**高德**，OSM 仍可在菜单里选；另加瓦片探测（HEAD 请求 4 秒超时）与地图区可见提示，不再只给一块空白 |
| 加完节点看不到点在哪 | 首个节点自动放大到 16 级并居中；后续节点落在视野外时自动重新取景（`RouteMapController.isVisible`） |
| 想把路线带到别处 | 新增 **GPX 导入/导出**（`route-core` 的 `GpxCodec`，子代理实现）：`trk/trkseg/trkpt` 单段折线，读写都按 WGS-84 |
| 想在模拟器里验证 | 调试包增加 `x86_64`（release 仍只有 `arm64-v8a` / `armeabi-v7a`），并在 API 35 模拟器上跑通「运行 → 探针读到 mock 帧 → 传送 → GPX 往返 → 高德底图坐标对齐」全流程 |

测试：**144 个 JVM 用例**（route-core 78 / simulation-core 24 / app 42），lint 0 error（app 16 warning、探针 1 warning）。
模拟器实测的截图、系统读数与复现步骤见 `docs/04_模拟器实测记录.md` 与 `delivery/evidence/emulator/`；

## 构建

需要 JDK 17+（本项目用 JDK 21 实测）、Android SDK（platform 35、build-tools 35.0.0）。
工程已放在**纯 ASCII 路径** `E:\agri-run\route-workshop`，直接构建即可，不需要 `subst`。
（早期工程位于含中文的路径，Gradle 测试 worker 会 `ClassNotFoundException`、混用盘符会报
`different roots`，因此曾用 `subst` 兜底；2026-10-26 已把目录迁移成 ASCII 名字，相关开关一并移除。
排查记录见 `docs/BUILD.md`。）

```powershell
$env:JAVA_HOME='D:\Java\jdk-21'; $env:ANDROID_HOME='E:\Android\Sdk'
Set-Location E:\agri-run\route-workshop
.\gradlew.bat :route-core:test :simulation-core:test :app:testDebugUnitTest
.\gradlew.bat :app:assembleRelease :app:lintDebug
```

## 已知限制

- 任务书没有给出 B 操场的确认坐标，所以**没有任何预置地点**；示例路线使用 `(0, 0)` 附近的合成坐标。
- 模拟位置能否被第三方 App 采信，取决于系统版本、厂商 ROM 与对方的风控策略，本工具不做承诺。
- OSM 公共瓦片有使用政策（署名、UA、禁止批量抓取），正式长期使用应换成自建或商业瓦片源。
- 未在真机（真我 GT Neo5）上实测的功能都在 `delivery/TEST_REPORT_测试结果.md` 中显式标注「未实测」；
  0.1.3 在 API 35 模拟器上实测了「运行 → 独立探针读到 mock 帧」这条主链路，但模拟器不等于真机 ROM。
