UNLOOP 是一个完全运行在手机本地的校园工具：在地图上画出路线，让系统定位沿着路线跑圈；让位置停在指定地点；把教务课表、学习通作业和桌面小组件收进同一个应用。没有服务器和账号体系，路线、课表、作业缓存与跑步记录都只保存在你自己的手机上。

## 主要功能

| 功能 | 能做什么 |
| --- | --- |
| 校园快跑 | 在地图上选一条路线或自己点一条，选好配速与圈数后开始跑圈。步行 / 跑步 / 骑行分别记住速度，运行中随时调速；暂停、继续、结束与结果统计都在同一页完成，跑过的里程会进跑圈历史。 |
| 悬浮控制台 | 运行中切到任何界面，都有一个小球可以展开：暂停、继续、结束，或用摇杆微调位置、切换速度档。在地图页会自动收起，不挡视线。 |
| 虚拟定位 | 搜索地点、粘贴经纬度或地图链接，也可以直接点地图；选点后让系统定位保持在原地。常去的点位可以收藏，下次一键传送。 |
| 课表 | 从教务系统一键导入（内置多所高校，也可手动填写教务地址），或点空白格手动添加。支持多学期、调课 / 停课 / 补课 / 节假日、冬夏令时作息、周次切换，以及导出 `.ics` 与分享码。 |
| 作业 | 在应用内登录学习通，按截止时间汇总近期作业并标注状态；支持缓存与自动刷新，触发安全验证时保留已读结果，可在应用内打开官方验证页继续。 |
| 桌面小组件 | 「今日课表」2×2 与「双日课表」4×2 / 4×3 两种样式，不解锁也能看到今天和下一个有课日。 |
| 提醒中心 | 课前提醒、作业截止提醒，以及调课 / 停课等会改变上课安排的事项，集中在一处查看和开关。 |
| 备份与恢复 | 把路线、课表、作业、跑步记录与设置导出成 JSON 文件，换手机或重装前一键恢复，恢复前自选要包含的内容。 |
| 检查更新 | 在应用内检查、下载并安装新版本；自动选择可用线路，安装前校验包名与签名。 |

此外还有：跑圈历史与统计、路线 GPX 导入导出、自然变速与路线扰动、桌面长按快捷方式（校园跑 / 虚拟定位 / 今日课表 / 查作业）、通知栏快捷设置磁贴（悬浮台 / 虚拟定位），以及跟随系统的浅色 / 深色界面。

## 下载与安装

- **系统要求**：Android 10（API 29）及以上。
- 从 [Releases](https://github.com/Sek1ro-oka/AGRI-RUN/releases/latest) 下载最新 APK（当前 0.13.0）。首次安装需要允许「安装未知应用」。
- **升级**：0.9.5 及以上版本可直接覆盖安装；更早版本签名不同，需要先卸载再装（本机数据会被清空，建议先导出备份）。
- 首次打开会依次展示权限、学习通与教务课表三步引导，任何一步都可以先跳过，之后从设置页补上。

## 第一次使用

### 让模拟位置生效

1. 打开系统「开发者选项」。
2. 在「选择模拟位置信息应用」里选择 **UNLOOP**。
3. 回到应用，进入「校园快跑 → 右上角运行设置 → 模拟定位与权限检查」，按清单确认定位权限、系统定位开关、通知权限与电池优化都已就绪。
4. 想独立核对系统是否真的收到了坐标，可以使用仓库里的「定位探针」模块（独立包名，需自行构建安装）。

### 跑一次校园跑

1. 进入「校园跑」，在地图上选一条预设路线，或者点出自己的路线；首尾相连即为闭合路线，不闭合时可在「到终点」选择停止或原路往返。
2. 选择步行 / 跑步 / 骑行配速（长按可修改），按需设置圈数；不设圈数就持续跑到手动结束。
3. 点「开始跑圈」。运行中可以随时暂停、继续、调速或结束；切到其他应用后，用悬浮控制台完成同样的操作。
4. 结束后会显示本次的距离、用时与配速，并记入跑圈历史。
5. 进阶：运行设置里可以开启自然变速与路线扰动，路线支持 GPX 导入导出；在设置中输入激活码 `ZNLU` 可导入 A操 / B操 / 衣锦三条预设路线。

### 虚拟定位

搜索地点、粘贴经纬度或地图链接，也可以直接点地图选点；确认后位置会保持在原地。常用位置可以收藏，下次从列表里直接传送。

### 课表与作业

- **课表**：首次导入时选择学校（内置多所正方高校的登录页，也可手动填写其他学校的教务地址），在应用内登录后读取并导入课表；也可以点空白格手动添加课程或事件。导入后会按课表自带的周次自动定位本周，学期总周数与作息时间可以随时调整。校外访问教务系统通常需要先连接学校 VPN。
- **作业**：在应用内登录学习通，作业会按截止时间汇总并标注「待完成 / 待批阅 / 已完成 / 已截止」，支持缓存与自动刷新。

### 桌面小组件与快捷入口

- 长按桌面空白处添加「今日课表」或「双日课表」小组件。
- 长按应用图标，可以直接进入校园跑、虚拟定位、今日课表或查作业。
- 通知栏的快捷设置里可以添加「悬浮台」与「虚拟定位」磁贴。

## 数据与隐私

- 没有服务器与账号体系，应用不上传你的任何数据。
- 路线、课表、作业缓存、跑步记录与偏好只保存在应用私有目录；备份文件不包含学习通登录状态、更新下载缓存与正在进行的跑步。
- 需要联网的只有：地图底图与地点搜索、学习通 / 教务官方网页、以及检查更新。学习通登录沿用官方网页，应用只保存登录 Cookie，可随时切换账户或重新登录。
- 备份与恢复在「设置 → 备份与恢复」，导出前可以勾选要包含的内容。

## 常见问题

**跑圈开始了，但目标应用里位置不动或里程不累计？** 模拟位置是否被采信，由系统版本、厂商 ROM 与目标应用自己的风控策略决定，本工具不做承诺。先用「模拟定位与权限检查」和「定位探针」确认系统确实收到了坐标；如果系统已接受而目标应用仍不动，说明是对方主动过滤了模拟位置。

**学习通提示安全验证？** 应用会保留已经读到的作业结果，并给出打开官方验证页的入口；在应用内完成验证后继续刷新即可。

**导入课表失败？** 多数学校的教务系统只允许校园网访问，校外请先连接学校 VPN；也可以在登录页手动填写正确的教务地址。

**小组件不刷新？** 课表有变化时小组件会同步刷新；如果长期不刷新，检查系统是否限制了应用后台活动，或重新添加一次小组件。

**检查更新下载慢或失败？** 应用会同时尝试直连与公共加速镜像；安装阶段还需要允许「安装未知应用」。网络受限时可以在 Releases 页手动下载新版本覆盖安装。

**换手机怎么迁移数据？** 在旧手机「设置 → 备份与恢复」导出 JSON，在新手机用「恢复备份」导入即可。

## 仓库结构

```
app/              主应用（Android）
route-core/       纯 Java：路线几何、按距离取点与运行状态机
simulation-core/  纯 Java：模拟位置会话（可注入 API，便于单测）
location-probe/   独立包名的定位探针，用来核对系统是否收到模拟位置
docs/             设计说明、构建记录、实测记录与更新说明
samples/          合成坐标示例路线（不是真实地点）
```
