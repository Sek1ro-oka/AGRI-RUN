# Legion

> **免责声明**：本项目是个人课程学习 / 实践项目，仅供学习交流，**严禁任何形式的商业使用**。本项目为独立个人项目，与任何机构官方无关，不代表其立场；学习通等第三方服务的名称、数据与页面归其权利人所有。请遵守相关规章制度和第三方服务条款，使用本工具产生的风险由使用者自行承担。

一个面向校园生活的 Android 小工具：**校园快跑**在地图上点出闭合路线，用 Android 系统模拟位置沿路线跑圈；**作业查询**可绑定学习通读取课程作业，并提供一份完全本地的周课表。

- 包名：`org.localroute.app`
- 代码仓库：<https://github.com/Sek1ro-oka/AGRI-RUN>（不含 APK、签名密钥、`local.properties` 与高德 Key）
- 最低系统：Android 10（API 29），编译 SDK 35
- 无服务器，路线、课表与学习通 Cookie 都只存在手机本地；地图瓦片和学习通网页是可选联网项，其余功能离线可用
- 附带一个独立包名的小工具 **定位探针**（`org.localroute.probe`），用来独立验证“系统确实收到了坐标”

> 本应用不修改、不注入、不 hook 任何第三方应用；是否采信模拟位置由系统与第三方应用自己决定。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 校园快跑 | 主页入口；设置页含配速、圈数、自然变速、路线扰动滑条与「设置」环境检查，跑圈地图页选择目标路线并控制悬浮窗开关（默认关闭，开启后只在 Legion 切到后台时显示）；路线扰动越大每圈轨迹越不重合，偏移始终限制在跑道内；内置 A操 / B操 预设路线，在应用设置的激活码里输入 `ZNLU` 解锁（激活只生效一次，之后可像普通路线一样重命名、重绘或删除）；绘制的航点会自动去重、去手抖尖刺并平滑成连续轨迹，跑者标记在两次定位快照之间补帧滑动；运动结束（含悬浮窗长按结束）直接回到跑圈地图显示本次结果，模拟位置回填到真实位置后交还系统定位 |
| 作业查询 | 主页入口；首次进入在官方 WebView 登录学习通，只保存登录 Cookie；作业优先一次读取聚合作业页（失败时退回逐课程），按截止时间从早到晚排序、只保留近一周，近期已截止的压在底部，并标注待完成 / 待批阅 / 已完成 / 已截止；支持缓存、下拉式刷新、30 分钟自动刷新与重新登录；触发学习通安全验证时保留已读结果，并可在应用内打开官方验证码页，完成验证后继续读取；标题与课程名完整换行显示，刷新或滚到底不再自动回顶 |
| 课表 | 作业页底部切换；导入教务系统导出的课表 PDF（读取文字坐标还原星期、节次、周次、地点与教师），也可点击空白格添加课程或事件、点击课程卡片修改或删除；按周一至周日 × 节次绘制（最多 15 节）；冬令时 / 夏令时两套独立作息，上午、下午、晚课各可设置 1–6 节及三个起点，每节时长 30–120 分钟；普通课间与大课间可调，午休与晚餐由时段空档自动推导；课表按屏宽自适应，周一至周日七列同屏 |
| 学习通设置 | 作业页右上角独立设置页：切换账户、重新导入课表 PDF、添加课程、清空课表、按冬夏令时分别调整每段节数与上课时间、普通课间与大课间并恢复本季默认 |
| 检查更新 | 主页入口（作业查询下方）；读取 GitHub 最新 Release 并与当前版本比较，发现新版本后自动探测 GitHub 直连与公共加速镜像、选最快线路下载 APK，安装前校验包名、签名与发布摘要；无 Release、版本不高于当前或网络失败会给出对应提示 |
| 设置 | 主页底部入口；语言（当前仅展示简体中文，暂未开放切换）与激活码（输入 `ZNLU` 解锁 A操 / B操 预设路线，激活只生效一次） |
| 地图与路线 | MapLibre + 高德瓦片底图，卫星 / 标准两个图层可切，默认卫星；单击加点，拖动/双指缩放不会误加点；加第一个点或点落在视野外时自动取景；支持撤销、清空、手动输入经纬度（WGS-84，纬度在前）、实时显示单圈长度；支持 GPX 导入导出 |
| 模拟定位 | `LocationManager.addTestProvider` + `setTestProviderEnabled` + `setTestProviderLocation`，GPS 必测，NETWORK/FUSED 支持则一并提交；前台服务常驻通知，锁屏继续输出；可在通知与悬浮控制台暂停 / 继续 / 停止 |
| 诊断与自检 | 诊断页把「应用提交的坐标」与「系统读回的坐标」并排对比，给出「系统已接受 / 偏差过大 / 未收到 / 无模拟标记」结论；设置页可逐项检查模拟位置权限、定位权限、系统定位开关、通知权限与电池优化 |
| 本地数据 | 路线、课表、偏好与 Cookie 均保存在应用私有目录；路线写入走临时文件 + fsync + 原子替换，损坏文件隔离到 `corrupt/` |

## 快速开始

1. 从 [Releases](https://github.com/Sek1ro-oka/AGRI-RUN/releases) 安装正式包。
2. 手机 **开发者选项 → 选择模拟位置信息应用 → Legion**。
3. 打开 App 授予定位权限，打开系统定位；进入「校园快跑 → 设置」逐项确认环境检查通过。
4. 进入跑圈地图，绘制或选择一条闭合路线，填写配速与圈数后点「开始」。
5. 切到后台后可以用悬浮控制台暂停 / 继续；长按悬浮窗上方中间的按钮结束运动。
6. 用「定位探针」独立复核：开始监听后应看到坐标在变、并标注为模拟位置。

## 构建

需要 JDK 17+（本项目用 JDK 21 实测）与 Android SDK（platform 35、build-tools 35.0.0）。工程路径建议使用纯 ASCII。

```powershell
$env:JAVA_HOME='D:\Java\jdk-21'
$env:ANDROID_HOME='C:\Users\<user>\AppData\Local\Android\Sdk'
Set-Location E:\agri-run\route-workshop
.\gradlew.bat :route-core:test :simulation-core:test :app:testDebugUnitTest
.\gradlew.bat :app:assembleRelease :app:lintDebug
```

高德 Key 通过 `local.properties` 的 `amapKey=` 注入，不提交到仓库。

## 已知限制

- 模拟位置能否被第三方 App 采信，取决于系统版本、厂商 ROM 与对方的风控策略，本工具不做承诺。
- OSM 公共瓦片有使用政策（署名、UA、禁止批量抓取），正式长期使用应换成自建或商业瓦片源。
- 未在真机上实测的功能会在测试报告中显式标注「未实测」；模拟器结果不等于真机 ROM 行为。
- 检查更新读取 GitHub Releases 的匿名接口，要求发布仓库公开且 Release 附带 APK；直连不可用时会尝试公共加速镜像，镜像速度取决于线路。安装 APK 还需用户允许「安装未知应用」；应用会核对包名、签名证书与 Release 摘要后才交给安装器。
