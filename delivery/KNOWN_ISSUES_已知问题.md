## 二、功能性限制

1. **没有预置地点**。任务书未确认 B 操场坐标，`samples/` 里只有 `(0, 0)` 附近的合成数据。
   真实路线需要用户在地图上点选，或用「手动输入」填经纬度。
2. **路线恒闭合**，不支持开放路线；单点草稿能保存但不能运行。
3. **只支持 WGS-84 输入**，不自动做 GCJ-02（火星坐标）纠偏；直接粘贴高德/腾讯地图的坐标会偏移几百米。
4. **地图瓦片来自 OSM 公共服务**：需要网络、有使用政策限制（署名、UA、禁止批量抓取），
   长期使用应换成自建或商业瓦片源；本项目不做离线瓦片缓存。
5. **不能导出轨迹**（无 GPX/GeoJSON 导出），也不记录历史运行。
6. **速度是“沿路线匀速”的抽象**，不模拟起跑加速、弯道减速或 GPS 抖动；提交的精度固定为 3 米。
7. **不保证第三方 App 采信**：是否接受模拟位置、是否有额外风控，完全由对方决定。本工具不修改、
   不注入、不 hook 任何第三方应用。
8. **定位探针是 debug 包**，包名 `org.localroute.probe`，与主程序无数据共享。

## 三、工程/构建限制

1. 工程已迁移到纯 ASCII 路径（`E:\agri-run\route-workshop`）；早期在含中文路径下必须用 `subst` 映射盘符构建，这一点已在 2026-10-26 解决；
   直接在同一条路径混用 `E:\` 与 `R:\` 会报 `this and base files have different roots`。
2. Gradle 8.11.1 不支持 JDK 25；构建必须 `JAVA_HOME=D:\Java\jdk-21`。
3. Gradle 发行包走腾讯镜像（`services.gradle.org` 在本机不可达）。
4. release 使用**本机自签名证书**，不是公开发布证书；换机器重新生成证书会导致无法覆盖安装。
