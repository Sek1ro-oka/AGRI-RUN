## 二、功能性限制

1. **没有预置地点**。任务书未确认 B 操场坐标，`samples/` 里只有 `(0, 0)` 附近的合成数据。
   真实路线需要用户在地图上点选，或用「手动输入」填经纬度。
2. **路线默认闭合，但 0.1.1 起可关闭闭合**：关闭后按「原路返回」计圈（一圈 = 往返全程），不支持任意开放折线；
   单点草稿能保存但不能运行，需要 2 个以上不同的点。
3. **只支持 WGS-84 输入**，不自动做 GCJ-02（火星坐标）纠偏；直接粘贴高德/腾讯地图的坐标会偏移几百米。
4. **地图瓦片来自 OSM 公共服务**（默认 OSM 官方，可切 OSM France / OSM Germany）：需要网络、有使用政策限制（署名、UA、禁止批量抓取），
   长期使用应换成自建或商业瓦片源；本项目不做离线瓦片缓存，无网络时地图空白但有提示，手动输入与单点发送仍可用。
5. **不能导出轨迹**（无 GPX/GeoJSON 导出），也不记录历史运行。
6. **速度是“沿路线匀速”的抽象**，不模拟起跑加速、弯道减速或 GPS 抖动；提交的精度固定为 3 米。
7. **不保证第三方 App 采信**：是否接受模拟位置、是否有额外风控，完全由对方决定。本工具不修改、
   不注入、不 hook 任何第三方应用。
8. **定位探针是 debug 包**，包名 `org.localroute.probe`，与主程序无数据共享。

## 0.1.2 新增的已知限制

1. **高德瓦片是非官方接口**（`webrd0{1..4}.is.autonavi.com/appmaptile?...`）：没有 SLA，可能随时改地址、加校验或限流；也不提供正式的署名条款。因此它只是可选项，默认仍是 OSM；商用或长期使用应改用高德官方 SDK/密钥。
2. **百度地图未接入**：其瓦片是 BD-09 私有矢量接口，必须集成官方 SDK 与 key，与本项目「不接第三方 SDK」的取舍冲突。
3. **GCJ-02 换算精度**：用的是公开近似算法（克拉索夫斯基椭球），在城市尺度上误差通常在 1–2 米内，与官方 SDK 的加密结果**可能有米级差异**；边界地区（`outOfChina` 判定线附近）可能出现几米跳变。单测只断言往返误差 < 0.5 米与偏移量级，未与官方数据逐点对比。
4. **位置自检只读 `getLastKnownLocation`**：不主动请求更新，因此目标 App 刚被杀或系统缓存过期时可能显示「未收到」；它证明「系统里有一个和本应用提交一致的坐标」，不能证明「目标 App 采信了它」。
5. **`fused` provider 基本不可用**：它由 Google Play 服务注册，`addTestProvider("fused")` 在多数机型抛 `IllegalArgumentException`；自检里显示「不可用」属预期，不代表应用没提交。
6. **传送是「搬家」，不是「轨迹」**：单点模式只提交固定坐标与速度 0，不会让目标 App 记录距离；想要距离必须用路线模式。
7. **运行中禁止传送**：有路线在跑时选传送会被拒绝，需要先停止。这是为了避免一个 runId 两个入口。

## 三、工程/构建限制

1. 工程已迁移到纯 ASCII 路径（`E:\agri-run\route-workshop`）；早期在含中文路径下必须用 `subst` 映射盘符构建，这一点已在 2026-10-26 解决；
   直接在同一条路径混用 `E:\` 与 `R:\` 会报 `this and base files have different roots`。
2. Gradle 8.11.1 不支持 JDK 25；构建必须 `JAVA_HOME=D:\Java\jdk-21`。
3. Gradle 发行包走腾讯镜像（`services.gradle.org` 在本机不可达）。
4. release 使用**本机自签名证书**，不是公开发布证书；换机器重新生成证书会导致无法覆盖安装。

## 四、独立审查后仍未闭环的项

第二轮另起只读 subagent 做过一次代码审查（详见 `TEST_REPORT_测试结果.md` 第 7 节），发现的问题已修并补测。以下问题**代码层面已知、但没条件验证或明确不做**：

1. `SimulationService`（700+ 行）**没有任何自动化测试**：Handler 投递、通知、WakeLock、完成/停止分支全靠静态走查，真机行为未验证。
2. 崩溃残留的测试 provider 是否在 system_server 里跨进程存活，未在真机验证；代码已做「先清理再创建」，真机仍可能报「设备不支持」。
3. `fused`（GMS）provider 能否注册因 ROM 而异；注册失败会被跳过并记入 `skippedProviders`，界面只显示列表、不解释具体原因。
4. Android 14 上从通知 Action 冷启动前台服务的限制未验证（代码先 `ensureForeground` 再投递命令）。
5. 诊断页读日志、导出文本仍在主线程做轻量 IO，未做 StrictMode 全面排查。

## 0.2.2 仍未验证的事

- 高德 SDK 引擎在**真机**上的实际表现（空白地图是否消失、点击与传送是否恢复）：本机模拟器是 x86_64，按策略退回瓦片引擎，无法覆盖这条路径；请在 arm 真机上复验。
- `getCurrentLocation` 实时定位在 Android 10（API 29）上的行为：代码走 `SDK_INT >= R` 分支，低于 R 只提示「请先用其它地图应用定位一次」。
- 菜单「定位到当前位置」读取的是系统最后已知位置，可能是几分钟前的缓存；界面弹窗会显示 provider 名称，但不显示时间。
