# 路线工坊 0.1.2 — 安装与使用

> 离线工具：在地图上点出一条路线（闭合或原路返回），用系统「模拟位置」把匀速跑圈的坐标喂给系统；
> 也可以直接发送一个固定坐标。不联网同步、不登录、不上传，任何数据都只在本机。

## 一、两个 APK

| 文件 | 包名 | 作用 |
| --- | --- | --- |
| `路线工坊-0.1.2-release.apk` | `org.localroute.app` | 主程序（versionCode 3，可覆盖安装 0.1.0/0.1.1 并保留路线） |
| `定位探针-0.1.0-debug.apk` | `org.localroute.probe` | 旁证工具：独立读取系统位置，确认坐标真的进了系统（探针本版未改动） |

> 定位探针用的是 debug 包（包名带 `.debug` 后缀的是主程序的调试包，二者可共存，但**只需要装 release 主程序**）。
> 探针只读取位置，不做任何修改，可以随时卸载。

## 二、安装

1. 把两个 APK 传到手机（数据线 / 微信文件传输助手等），点击安装；系统提示“未知来源”时允许。
2. 或电脑安装：

```powershell
$adb = 'E:\Android\Sdk\platform-tools\adb.exe'
& $adb install -r 路线工坊-0.1.2-release.apk
& $adb install -r 定位探针-0.1.0-debug.apk
```

3. 已经装过 0.1.0 时直接覆盖安装即可（版本号 2 > 1），已保存的路线不会被清掉。

## 三、首次配置（必须做，否则无法提交模拟位置）

1. **打开开发者选项**：设置 → 关于手机 → 连续点「版本号」7 次。
2. **选择模拟位置信息应用**：设置 → 系统 → 开发者选项 → 「选择模拟位置信息应用」→ 选 **路线工坊**。
   （不同 ROM 路径略有差异，通常在“开发者选项”里搜“模拟”。）
   **0.1.1 起本应用才会出现在这个列表里**：0.1.0 的清单缺少 `ACCESS_MOCK_LOCATION` 声明，而系统的应用选择器
   正是按这个权限过滤候选应用。如果升级后仍看不到，请确认设置里显示的版本是 0.1.2（versionCode 3）。
3. **授予定位权限**：首次打开 App 会弹窗，选「仅在使用中允许」并**允许精确位置**。
4. **打开系统定位开关**（下拉通知栏的定位图标）。
5. 打开 App → 右上角菜单 →「设置检查」→ 点「重新检查」，五项应全绿：
   模拟位置应用 / 定位权限 / 系统定位 / 通知权限 / 电池优化。

> 设置检查里的「检测模拟位置权限」会临时创建并立刻删除一个测试 provider，用来确认系统放行；
> **运行中请不要点它**。

## 四、画一条路线

1. 地图加载后（需要网络拉瓦片；瓦片失败也不影响已保存路线运行），**单击**地图添加节点。
   拖动地图、双指缩放**不会**误加点。
2. 至少 2 个点，建议 4 个点围出操场一圈；面板上的「单圈」会实时显示长度。
3. 点错了用「撤销」，想重来用「清空」。
4. 也可以点「手动输入」，按 `纬度,经度` 一行一个点粘贴（WGS-84，纬度在前）。
5. 菜单「保存路线」写盘；「加载路线」列出已保存的路线；「重命名」「删除」对当前路线生效。

### 闭合还是原路返回（0.1.1）

- 菜单「闭合路线」默认勾选：**最后一点连回起点**，单圈 = 围着图形走一圈（含回到起点那条边）。
- 取消勾选后不再自动连回起点：跑到最后一个点后**沿原路返回**，一圈 = 单程的两倍。
  面板文案会变成「不闭合（原路返回）· 单圈 …」，圈数按往返计算。
- 切换闭合状态算一次未保存修改，需要重新「保存路线」才会写进 JSON。

## 五、跑起来

1. 填速度（0.5–60 km/h，默认 9）与圈数（1–1000，默认 5）。
2. 点「开始」：状态变成「启动中」→ 检查权限/模拟应用/定位开关 → 创建测试 provider → 首次提交成功才变「运行中」。
   如果失败，界面会直接显示原因（权限、模拟应用未选、定位关闭、provider 不支持等）。
3. 通知栏出现常驻通知，可直接「暂停 / 继续 / 停止」。
4. 面板实时显示：状态、当前位置、速度、累计距离、已完成圈数、有效运行时间（暂停不计时）。
5. 跑满设定圈数后自动停止：位置精确回到起点，状态「已完成」，不额外多跑。
6. 想中途结束点「停止」；重复点不会产生第二个任务。

## 六、只发一个固定位置（0.1.1）

1. 菜单 →「发送单点位置」。
2. 纬度/经度默认填当前地图中心，也可以手改（WGS-84，纬度在前）。
3. 点「发送」：状态变「运行中」，面板的圈数显示为「单点」，提示「单点位置发送中（速度 0）」。
4. 前台服务每 500 ms 把同一个坐标提交一次，直到你点「停止」。
5. 用定位探针可以独立验证：应看到同一个坐标反复出现、标注「模拟位置」、速度 0。

> 单点模式与路线模式共用同一套前台服务与通知；同一时间只允许一个任务。
> 如果此时正在跑路线，会提示先停止。

## 六点五、传送到地图上选的点（0.1.2）

想把位置直接搬到一个新地方，不用画路线：

1. 菜单 → **传送到地图选点**，底部提示「在地图上点一下要传送到的位置」。
2. 在地图上点一下。应用会把这一点换成 WGS-84（当前底图是高德时会先做 GCJ-02 → WGS-84），
   立刻启动单点模式：速度 0、坐标固定，通知栏显示「单点位置 · 已在目标点」。
3. 想换点：再点一次菜单进入传送模式重新选；想结束：通知栏或页面上点「停止」。
4. 运行中（有路线在跑）点传送会被拒绝并提示先停止——这是故意的，避免两个入口抢同一个模拟位置。

注意：传送只负责「让系统收到这个坐标」。目标 App 是否采信，取决于它自己是否过滤模拟位置。

## 六点六、换成高德底图（0.1.2）

菜单 → **地图瓦片源** → **高德地图（GCJ-02）**。

- 高德底图用的是 GCJ-02（火星坐标），本应用内部一律用 WGS-84，所以显示和点选时都会自动换算；
  换底图前后路线**不会漂移**，在高德底图上新点的点，切回 OSM 也在同一位置。
- 高德的瓦片地址是公开但**非官方**的接口，也可能因为网络或限流加载不出来。加载不出来时按上一节排查，
  或者切回 OSM 官方。
- 百度地图没有接入：它的瓦片是 BD-09 私有格式，必须用百度官方 SDK 和 key，本应用不接第三方 SDK。

## 六点七、位置自检：系统到底收没收到（0.1.2）

菜单 → **诊断信息**，顶部黄色区块「位置自检」每 3 秒刷新：

- `模拟位置` 一行是**本应用最后提交的坐标**；
- 下面按 `gps / network / fused` 列出**系统读回的坐标**、是否带「模拟」标记、读数距今几秒；
- 最后一句话给结论：
  - **系统已接受**（偏差在 20 米内且带模拟标记）→ 系统这一层通了，如果目标 App 还不动，就是它在自己过滤模拟位置；
  - **偏差过大** → 有别的应用或系统服务在覆盖这个坐标（常见于同时开了别的虚拟定位工具）；
  - **未收到** → 权限、模拟位置应用选择或系统定位开关有问题，回到「三、首次配置」；
  - **无模拟标记** → 读回的是真实定位，说明模拟位置没生效（多半是没被选为模拟位置应用）。
- `fused` 显示「不可用」是正常的：它由 Google Play 服务注册，多数机型不接受测试 provider。

## 七、地图黑屏怎么排查（0.1.1）

0.1.1 起地图区域不再是纯黑（0.1.2 又增加了高德源）：

- 打开时先铺**浅灰底**并显示「地图加载中…」。
- 瓦片样式 10 秒内没就绪，或者地图报错，底部会出现一条原因提示（例如“加载 OpenStreetMap 官方 超过 10 秒仍未完成（可能是网络无法访问该瓦片服务）”）。
- 菜单 →「地图瓦片源」可切换三种公开栅格源：**OSM 官方**、**OSM France**、**OSM Germany**。
  切换后立刻重建样式，选择会记住。
- 地图不可用时，**手动输入坐标**和**发送单点位置**仍然可以正常使用。

> 三种源都是公开服务，仍需要网络；离线地图不在本版范围。

## 八、用定位探针验证（推荐）

1. 打开「定位探针」→ 授予定位权限 → 点「开始监听」。
2. 回到路线工坊点「开始」（或发送单点位置）。
3. 探针列表应每 0.5 秒出现一行新坐标，并且标注「模拟位置」；「累计位移」会持续增长（单点模式不变）。
4. 停止后探针会汇总「共 N 个位置、累计位移 X 米、监听 Y 秒」。

> 探针只证明“系统里确实有坐标在动”，**不代表**第三方运动 App 一定采信模拟位置——那是对方的风控决定。

## 九、常见问题

| 现象 | 处理 |
| --- | --- |
| 开发者选项的列表里没有「路线工坊」 | 确认装的是 0.1.2（versionCode 3）；0.1.0 缺少 `ACCESS_MOCK_LOCATION` 声明所以不会出现在列表 |
| 开始后立刻报「未选择模拟位置应用」 | 回开发者选项重新选一次「路线工坊」，部分 ROM 会在重启后清空该设置 |
| 报「系统定位开关已关闭」 | 打开系统定位；部分 ROM 的“省电模式”也会关定位 |
| 提示调度中断、自动暂停 | 系统冻结了后台（省电策略）。把路线工坊加入「电池优化白名单」后点「继续」 |
| 地图黑/空白/加载失败 | 看底部原因条；换网络或菜单换瓦片源；不影响手动输入与单点发送 |
| 点了三个点就自动连回起点 | 菜单「闭合路线」取消勾选即可（0.1.1） |
| 想只把位置放在某一点 | 菜单「发送单点位置」→ 输入坐标 → 发送（0.1.1） |
| 通知栏没有暂停/继续按钮 | 通知被折叠，长按/下拉展开；或在系统设置里允许本应用通知 |
| 第三方 App 里看不到移动 | 确认它拿到了定位权限；确认它是**前台**在记录；本工具不对第三方行为负责 |
| 想彻底清干净 | 点「停止」→ 退出 App；必要时在系统设置里撤销「模拟位置信息应用」 |

## 十一、数据与卸载

- 路线存在应用私有目录 `files/routes/<路线id>.json`，`versionCode` 升级覆盖安装会保留。
- 0.1.1 的 JSON 多了一个 `closed` 字段；0.1.0 存的文件没有这个字段时按「闭合」处理。
- 卸载 App 会一并删除这些文件；需要备份就用 debug 包的 `run-as`（见 `BUILD_构建说明.md`）。
- 本应用不收集任何个人信息，没有网络请求（除地图瓦片）。
