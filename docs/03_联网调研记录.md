**检索词 / 入口**

- `AGP 8.9 Gradle 8.11 compatibility`（Android 开发者文档 · Gradle 插件与 Gradle 版本对照表）
- `org.maplibre.gl android-sdk maven`（Maven Central 元数据 `maven-metadata.xml`）
- `androidx appcompat material lifecycle latest stable`（Google Maven 索引 `dl.google.com/dl/android/maven2`）
- `Android 10 addTestProvider setTestProviderLocation`（Android 开发者文档 `LocationManager`）

| Espresso | 3.6.1 | Google Maven | Apache-2.0 | 同上 |
| org.json（参考实现） | 20240303 | Maven Central | JSON License（仅测试） | JVM 单测需要与 Android 同 API 的 `org.json`；只在 `testImplementation`，不进 APK |

**关键判断**

1. **不用 Gson/Moshi**：Android 平台自带 `org.json`，路线文件结构简单；为省一个依赖、也避免反射与
   R8 的额外配置，`RouteJsonCodec` 直接手写映射。JVM 单测用 `org.json:json:20240303` 提供同 API 实现。
2. **compileSdk 35 / minSdk 29**：35 是当时本机已安装的平台；29 覆盖 `addTestProvider` 的现代行为，
   同时避开更老系统的权限差异。`targetSdk 35` 要求显式声明 `foregroundServiceType`，本项目已声明 `location`。
3. **JDK 21 而非 25**：Gradle 8.11.1 不支持 JDK 25 运行；本机 `D:\Java\jdk-21` 用于构建，`JAVA_HOME` 显式指定。
4. **OSM 公共瓦片**：`tile.openstreetmap.org` 允许轻量使用，但要求署名、可识别的 UA、禁止批量抓取与离线预取。
   本项目在样式 JSON 的 `attribution` 里写了 `© OpenStreetMap contributors`；**未**自定义 UA（MapLibre 默认 UA），
   长期正式使用应改为自建瓦片或商业瓦片服务（已记入 `KNOWN_ISSUES`）。

## 2026-10-26 · 模拟位置 API 行为

**检索词**：`LocationManager addTestProvider SecurityException mock location app`、
`setTestProviderEnabled requires ACCESS_MOCK_LOCATION`、`Location isMock API 31`

**要点**

- 需要用户在「开发者选项 → 选择模拟位置信息应用」里选中本应用，否则 `addTestProvider` 抛 `SecurityException`；
  应用自身不需要（也无法获得）`ACCESS_MOCK_LOCATION` 权限。
- `addTestProvider` 的参数在 API 30+ 有重载；本项目用旧签名（`Criteria` 版本）以兼容 29–35。
- 提交位置必须构造**完整**的 `Location`（provider、经纬度、精度、时间、`elapsedRealtimeNanos`），
  缺字段会导致下游 App 过滤掉该点。
- API 31+ 用 `Location.isMock()` 判断是否模拟位置，`isFromMockProvider()` 已废弃但仍可用于 29/30。

## 2026-10-26 · 打包/签名/安装

**检索词**：`apksigner verify v2 v3`、`aapt dump badging`、`adb install -r`、`foregroundServiceType location`

**要点**

- `apksigner verify --print-certs` 可校验签名方案与证书指纹；`aapt2 dump badging` 可核对包名/版本/权限。
- `foregroundServiceType="location"` 必须与 `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_LOCATION` 权限一起声明，
  否则 Android 14+ 启动前台服务会抛 `SecurityException`。
- 覆盖安装（同包名、同签名、更高 versionCode）会保留应用数据，可用于验证 T24。
