# Legion / Finmori 视觉规范

布局参考 [Finmori](https://github.com/KhoaSuperman/Finmori) 的间距、圆角、列表与胶囊导航；深浅配色参考用户提供的应用截图，颜色定义于 `res/values*/finmori_colors.xml`。

- 背景与卡片：浅色 `#F5F6FA` / `#FFFFFF`；深色 `#12151C` / `#1D212C`。
- 品牌与交互：浅色 `#147C4B`；深色 `#8CDBAE`。正文、次级文字、边界和状态色分别定义，并跟随系统切换。
- 页面边距 20dp，主卡片圆角 20dp，按钮圆角 16dp；主要点击目标不小于 48dp。
- 首页采用模块标题、跑步状态卡、带圆形图标的学习服务行；学习页面的两个标签使用胶囊导航。内容区域各自滚动，系统栏通过 WindowInsets 留出空间。
- 独立按钮和卡片采用 120–150ms 缩放反馈；学习标签切换与页面过渡采用 160ms 淡化。系统动画关闭时跳过属性动画，地图和课表触摸手势不参与按压动画。
- 保留本机课表、学习通、路线和模拟服务的数据来源；首页的课表入口直接打开本地周视图。
