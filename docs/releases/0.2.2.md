# 路线工坊 0.2.2

本地运行的 Android 路线工具：在地图上点选路线、设定速度与圈数，用系统模拟位置按轨迹跑，可选跨应用悬浮窗快捷传送。无账号、无服务器、不采集数据。

## 本版内容

**0.2.2（versionCode 9）**

- 修：高德 SDK 引擎下地图一片空白、点不了地图、传送失效——MapLibre 的 `MapView` 仍压在 SDK 地图上并吃掉触摸事件；选中 SDK 引擎后立即隐藏它。
- 修：`MapView.getMap()` 在构造时为 null 导致永不重试；改为构造取一次、`onResume` 再取一次，拿到非空 map 才初始化。
- 新增菜单 **「定位到当前位置」**：读 GPS/网络/fused 的最后一次定位；都读不到时请求一次实时定位，拿到后地图居中放大并画跑者标记。

**0.2.1**

- 可选地图引擎：高德官方 3D SDK 10.0.600（需自备 `amapKey`，仅 arm ABI）。Key 缺失或架构不匹配时自动退回 MapLibre + 栅格瓦片。

**0.2.0**

- 新路线默认不闭合；工具栏下方固定「将当前末点连接到第一个点」；终点策略三选一（到终点停止 / 原路往返 / 绕圈）；旧 v1 文件按原行为解释。
- 配速预设（行走 / 跑步 / 骑行，长按可改）与运行中改速（位置连续、不补算）。
- 切换地图源后重放当前草稿；起点橙色圈、顶点不逐个画点。
- 多段 GPX 只导入首段并提示原因。

## 安装

1. 下载 `RouteWorkshop-0.2.2-release.apk`（69.07 MB，本机自签名，可与旧版覆盖安装）。
2. 允许「安装未知来源应用」，安装后首次打开按提示授予定位与通知权限。
3. 系统设置 → 开发者选项 → 「选择模拟位置信息应用」选 `路线工坊`（0.1.1 起才会出现在列表里）。
4. 可选：同时安装 `LocationProbe-0.1.0-debug.apk`（包名 `org.localroute.probe`），用于独立确认系统确实收到了移动的模拟位置。

## 验证层次（如实说明）

- 自动化：JVM 单测全绿，lint 无 error；构建与测试记录见仓库 `delivery/evidence/`。
- 模拟器：API 35 x86_64 上实测过瓦片引擎、路线运行、传送、GPX、定位到当前位置。
- **真机未复验**：本版修的两处 SDK 问题只能在 arm 真机验证（模拟器会按策略退回瓦片引擎）。若地图仍空白，请把 logcat 里 `RouteWorkshop` 的几行发到 Issues；临时绕过办法是清空 `amapKey` 重新安装，强制走瓦片引擎。
